# KeimBook

Digitales Klassenbuch für Lehrkräfte – Mitarbeit, Wiederholungen, Hausübungen, Anwesenheit und Verhalten im Unterricht festhalten.

**App öffnen und installieren:** https://marzi44.github.io/keimbook/

- Läuft vollständig auf dem eigenen Gerät (iPhone, iPad, Android, Computer) – kein Konto, keine Cloud, keine Datenübertragung ins Internet.
- Optional mit PIN-Sperre: Daten werden auf dem Gerät verschlüsselt (AES-256).
- Freischaltung mit persönlichem Lizenzcode.

Anleitungen (Installationsanleitung, Kurzanleitung, Benutzerhandbuch) erhältst du gemeinsam mit deinem Lizenzcode.
